# Seashell

Seashell is a keyboard-first, highly customizable desktop shell for Hyprland built with Quickshell.

## Goals

- Keyboard-first interaction
- Modular architecture
- Unified theme synchronization
- Highly customizable UI and behavior
- Strong defaults without forcing one visual style

The first visual style is **Pixel Modern**, but Seashell is designed to support completely different themes and UI styles.
